AIDE · MODE D'EMPLOI

Bienvenue Cette application traduit le texte à l'écran (OCR) ou saisi à la main, dans plus de 20 langues. Voici comment utiliser chaque fonction.
Astuce : le dictionnaire hors-ligne fonctionne sans internet pour l'anglais et le français ; les autres langues nécessitent une connexion.
Sommaire

1. TRADUIRE UN TEXTE

  1. Choisis la langue source et la langue cible en haut de l'écran (ou inverse-les avec le bouton ).
  2. Écris ou colle du texte dans la zone TEXTE DÉTECTÉ.
  3. Appuie sur Traduire. La traduction apparaît dans TRADUCTION.
  4. Avec Traduction automatique activée (Réglages), la traduction se fait pendant la saisie.
Le bouton micro dicte le texte à voix haute. Les boutons Copier, Écouter et Partager agissent sur le résultat.

2. TRADUIRE L'ÉCRAN

  1. Appuie sur Partager l'écran et choisis la fenêtre à traduire.
  2. Appuie sur Scanner : le texte de la capture est reconnu puis traduit.
  3. Active Auto pour rescanner régulièrement, ou la surimpression pour afficher la traduction directement sur l'écran.
Le partage d'écran nécessite d'être servi en localhost ou https. Sinon, utilise l'import d'image.

3. TRADUIRE UNE IMAGE OU UNE PHOTO

  1. Appuie sur Importer une image (icône image) et choisis un fichier ou prends une photo.
  2. Lance le Scanner pour extraire et traduire le texte.
Raccourci : tu peux aussi coller une image avec Ctrl+V dans l'application.

4. SÉLECTIONNER UNE ZONE PRÉCISE

  1. Appuie sur le bouton zone (les quatre coins).
  2. Dessine un cadre sur la partie de l'image à traduire.
  3. Lance le Scanner : seule la zone sélectionnée est analysée.

5. SCAN AUTOMATIQUE

  1. Après un partage d'écran, active Auto pour retraduire en continu.
  2. Règle la fréquence avec Intervalle dans les Réglages (1 à 10 secondes).

6. BOUTON FLOTTANT

  1. Appuie sur l'icône jaune flottante pour ouvrir le menu rapide.
  2. Le menu permet de lancer le scan, changer de langue, copier, écouter, ou arrêter le partage.
  3. Déplace le bouton en le faisant glisser ; sa taille, son opacité et sa visibilité se règlent dans les Réglages.

7. DEMANDER À L'IA

  1. Pose une question à l'IA : elle voit la traduction en cours.
  2. Sans clé, l'IA gratuite (Pollinations) est utilisée.
  3. Pour Google Gemini, ajoute une clé API dans Réglages Assistant IA.

8. HISTORIQUE & DONNÉES

  1. Retrouve tes traductions dans l'onglet Historique.
  2. Exporter les partage dans une autre application.
  3. Tout effacer supprime définitivement l'historique.

CONSEILS POUR UN MEILLEUR OCR

  • Utilise une image nette, bien éclairée et de préférence bien cadrée.
  • Garde le prétraitement de l'image activé (netteté + contraste).
  • Vérifie la langue choisie avant de scanner.
